# Security Policy

At Aikido Security, we take security seriously. If you discover a security vulnerability in `@aikidosec/ci-api-client`, please report it responsibly.

## Supported versions

Only the latest published release of `@aikidosec/ci-api-client` on [npm](https://www.npmjs.com/package/@aikidosec/ci-api-client) receives security fixes. Please upgrade before reporting an issue, to confirm it still reproduces.

| Version | Supported |
| ------- | --------- |
| Latest release | ✅ |
| Older releases | ❌ |

## Reporting a vulnerability

**Please do not report security vulnerabilities through public GitHub issues, pull requests or discussions.**

Please report security vulnerabilities by emailing: **security@aikido.dev**

Please include as much of the following as you can:

- The affected version (`aikido-api-client --version` or the version in `package.json`) and your Node.js version and operating system.
- A description of the issue and its potential impact.
- Steps to reproduce, or a proof of concept.
- Any suggested fix or mitigation.

Do not include real Aikido API keys, tokens or sensitive data in your report. Redact them or use test values.
